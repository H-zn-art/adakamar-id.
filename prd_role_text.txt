1. Tujuan Dokumen
Dokumen ini menjelaskan pembagian role, hak akses, tanggung jawab, serta alur kerja masing-masing
pengguna pada sistem adakamar.id.
Sistem hanya memiliki 2 role internal:
Admin
Penulis Artikel
Pengunjung website tidak perlu membuat akun dan tidak termasuk role internal sistem.
2. Gambaran Sistem
adakamar.id merupakan website informasi dan discovery penginapan yang menyediakan:
Katalog penginapan.
Pencarian penginapan.
Filter penginapan.
Detail penginapan.
Informasi lokasi dan fasilitas.
Promo.
Artikel wisata dan informasi seputar Yogyakarta.
Inquiry/pemesanan melalui WhatsApp.

33. Kesimpulan
Struktur role adakamar.id dibuat sederhana:
┌─────────────────────────────────────────────┐
│                  ADAKAMAR.ID                │
├─────────────────┬───────────────────────────┤
│                 │                           │
│    PENGUNJUNG   │      INTERNAL SYSTEM      │
│                 │                           │
│                 │   ┌─────────┬─────────┐   │
│                 │   │  ADMIN  │ PENULIS │   │
│                 │   └────┬────┴────┬────┘   │
│                 │        │         │         │
│                 │        ▼         ▼         │
│                 │    ALL DATA   ARTICLES    │
│                 │                           │
└─────────────────┴───────────────────────────┘
Admin bertanggung jawab atas keseluruhan platform.
Penulis Artikel fokus pada pembuatan dan pengelolaan artikel miliknya.
Pengunjung fokus menemukan penginapan, membaca informasi, dan melakukan inquiry.
Dengan pembagian ini, arsitektur frontend Next.js, API Node.js/NestJS, database MySQL, dan authorization
dapat dibuat lebih sederhana, jelas, dan mudah dikembangkan.
